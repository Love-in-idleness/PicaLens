PicaLens 0.3.0 为 Debian 13 和 Ubuntu 26.10 提供同一个 amd64 安装包，带来多款新 GPU 超分与复古滤镜、滤镜锐化与后处理链、按应用记忆预设、画面裁剪、自动隐藏光标、一键截图以及全面增强的 Gamescope 启动页。

```sh
sudo apt install ./picalens_0.3.0-1_amd64.deb
```

安装包内含适配 KWin 6.3.6 与 6.7.5 的可选后台以及 GNOME 51 扩展。安装时会自动启用与系统 KWin 版本匹配的组件；Plasma 与 GNOME 用户升级后请重新登录会话以加载新版组件。

### 新功能

#### 画质、滤镜与指定 GPU
- **每预设指定渲染显卡**：新增独立 GPU 渲染进程（`picalens-render`），可按预设选择执行超分滤镜的渲染设备（按 PCI/平台设备路径持久化）。
- **新增 5 款 GPU 滤镜**：新增 **Anime4K（轻量）**、**CAS（自适应锐化）**、**Sharp-Bilinear（像素画）**、**xBRZ Freescale（像素画任意倍率）** 与 **CRT（Easymode 复古显像管）**，在 Plasma 6 交互全屏与 Portal 只读预览中均可使用。
- **滤镜参数与轻量后处理链**：支持在预设中调节 **锐化强度（0–100%）**，并可为任意 GPU 滤镜串联开启 **后处理锐化（CAS）** 与 **去色带（Deband）**。

#### 日常交互体验
- **按应用自动选择预设**：支持按 `app_id` / `WM_CLASS` 绑定缩放预设，在 Plasma 6 与 GNOME 51 按快捷键放大活动窗口时自动匹配。
- **自定义画面裁剪**：预设支持按逻辑像素裁剪源窗口上/下/左/右边距（KWin、GNOME 扩展与 Portal 预览均已适配，交互坐标与黑边隔离同步对齐）。
- **静止自动隐藏光标 & 放大期间防息屏**：在「设置 → 放大行为」支持设置 1 / 2 / 3 / 5 秒自动隐藏光标，以及放大期间阻止屏幕息屏休眠。
- **一键截图与目录定制**：支持设置默认截图保存目录（按时间戳自动防重名保存），新增 `picalens screenshot` 命令以支持在 Plasma 交互全屏与预览窗口中快速截屏。

#### Gamescope 启动页增强
- 补齐高频 Gamescope 选项（自动按本机版本检测可用性）：首选 Vulkan 显卡（`--prefer-vk-device` + 自动检测 PCI 设备 ID）、ReShade 着色器、画面旋转、最大缩放、显示器索引、相对鼠标、鼠标灵敏度、光标隐藏延迟、强制内部窗口全屏、HDR 亮度与逆色调映射、实时调度、允许撕裂与 Steam 集成。
- 支持自定义 **环境变量（`KEY=VALUE`）** 与 **额外 Gamescope 参数**，同步生效于直接启动与 Steam 启动选项复制。
