PicaLens 0.2.0 是 Wayland 预览版。这版加入可操作的 FSR 1 和 SGSR 全屏放大。

### 新功能

- Plasma 6 的 OpenGL 后台支持在放大时点击、滚动和使用键盘。FSR 1 和 SGSR 在 KWin 6.7.5 的原生 Wayland 与 XWayland 测试窗中均已验证。
- niri 26.04 和 Hyprland 0.53.3 支持等比交互全屏、FSR 1 和 SGSR，两类窗口均通过输入测试。交互功能分别需要匹配的 niri 补丁或 Hyprland 后台组件，可按源码中的说明构建。 [niri 构建说明](https://github.com/Love-in-idleness/PicaLens/blob/v0.2.0/docs/niri-experiment.md) · [Hyprland 构建说明](https://github.com/Love-in-idleness/PicaLens/blob/v0.2.0/docs/hyprland-experiment.md)
- 应用启动器使用新的像素风鹦鹉图标。
- DDE Wayland（Treeland）的交互放大仍在适配中，相关开发暂缓。系统 Portal 提供窗口采集时，可以使用只读预览。 [Treeland 功能讨论](https://github.com/linuxdeepin/treeland/issues/1728)

### 下载

| 发行版 | 安装包 |
| --- | --- |
| Ubuntu 26.10 amd64 | `picalens_0.2.0-1ubuntu26.10_amd64.deb` |
| Debian 13 amd64 | `picalens_0.2.0-1debian13_amd64.deb` |

以 Ubuntu 26.10 为例。

```sh
sudo apt install ./picalens_0.2.0-1ubuntu26.10_amd64.deb
```

KWin 后台是可选组件，仅在对应的发行版 KWin 版本匹配时启用。Plasma 用户升级后可重新登录以加载新版后台。 [各桌面使用说明](https://github.com/Love-in-idleness/PicaLens/tree/v0.2.0#使用) · [验证记录](https://github.com/Love-in-idleness/PicaLens/blob/v0.2.0/docs/verification.md)
