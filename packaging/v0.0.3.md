修复 KWin 6.7.5 上放大画面盖住软件光标的问题。光标使用 KWin 的原始形状、大小和点击位置。

| 发行版 | amd64 安装包 | 包内交互后台对应的 KWin |
| --- | --- | --- |
| Ubuntu 26.10 | `picalens_0.0.3-1ubuntu26.10_amd64.deb` | `4:6.7.5-0ubuntu1` |
| Debian 13 | `picalens_0.0.3-1debian13_amd64.deb` | `4:6.3.6-1+deb13u1` |

```sh
sudo apt install ./picalens_0.0.3-1ubuntu26.10_amd64.deb
```

升级后重新登录 Plasma，会话会加载新版 KWin 后台。打开 PicaLens 选窗，或用 `picalens toggle` 开始和停止。
