PicaLens 预览包适用于 amd64 的 Ubuntu 26.10 和 Debian 13。选取与你的发行版对应的 `.deb`。

| 发行版 | 安装包 | 包内交互后台对应的 KWin |
| --- | --- | --- |
| Ubuntu 26.10 | `picalens_0.0.2-1ubuntu26.10_amd64.deb` | `4:6.7.5-0ubuntu1` |
| Debian 13 | `picalens_0.0.2-1debian13_amd64.deb` | `4:6.3.6-1+deb13u1` |

例如 Ubuntu 26.10：

```sh
sudo apt install ./picalens_0.0.2-1ubuntu26.10_amd64.deb
```

主程序可以独立安装，KWin 的升级也可以照常进行。系统中的 KWin 与包内后台匹配时，PicaLens 自动提供交互放大。在其他版本上，支持窗口捕获的桌面 Portal 可以提供只读预览。

从应用菜单打开 PicaLens，点击 **Choose Window…**，再选中源窗口。也可用 `picalens toggle` 开始、取消选窗或停止放大。
