PicaLens 0.2.1 为 Debian 13 和 Ubuntu 26.10 提供同一个 amd64 安装包。

```sh
sudo apt install ./picalens_0.2.1-1_amd64.deb
```

安装包内含适配 KWin 6.3.6 和 6.7.5 的可选后台，安装时会自动启用与系统 KWin 软件包版本匹配的版本。GNOME 和其他兼容的 Wayland 桌面可以直接安装主程序。Plasma 用户升级后可重新登录以加载新版后台。

### 桌面支持

- Plasma 6 可用匹配的 OpenGL 后台运行 FSR 1 和 SGSR 交互放大。
- niri 和 Hyprland 的交互放大分别需要匹配的补丁或后台组件。 [niri 构建说明](https://github.com/Love-in-idleness/PicaLens/blob/v0.2.1/docs/niri-experiment.md) · [Hyprland 构建说明](https://github.com/Love-in-idleness/PicaLens/blob/v0.2.1/docs/hyprland-experiment.md)
- DDE Wayland（Treeland）的交互放大仍在适配中。 [Treeland 功能讨论](https://github.com/linuxdeepin/treeland/issues/1728)
