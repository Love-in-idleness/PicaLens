PicaLens 0.1.0 扩展了 Wayland 窗口放大和超分。这是一个预览版。

### 新功能

- 「缩放预设」新增 Lanczos 3、Scale2x、FSR 1 和 SGSR。FSR 1 先做 EASU 放大，再做 RCAS 锐化。两个 GPU 滤镜用于已打开窗口的只读预览，OpenGL 不可用时会回退到线性缩放。
- 「设置 → 外观」支持跟随系统、浅色和深色，切换立即生效。
- 带兼容后台的 Plasma 6 和 GNOME 51 可用全局快捷键放大当前窗口。GNOME 51 的交互模式通过随包扩展启用，XWayland 输入坐标转换另需匹配的 Mutter 组件。
- niri 和 Hyprland 接入系统选窗器、只读预览和 `picalens toggle`，采集支持由图形驱动协商的 DMA-BUF 格式。niri 已验证原生 Wayland 和 XWayland 选窗。两个桌面的完整取帧还需在带 DRM/GBM 设备的会话验证。

### 下载

| 发行版 | 安装包 |
| --- | --- |
| Ubuntu 26.10 amd64 | `picalens_0.1.0-1ubuntu26.10_amd64.deb` |
| Debian 13 amd64 | `picalens_0.1.0-1debian13_amd64.deb` |

```sh
sudo apt install ./picalens_0.1.0-1ubuntu26.10_amd64.deb
```

主程序可在兼容的 Wayland 桌面独立安装，Plasma 的可选交互后台在 KWin 版本匹配时加载。Plasma 用户升级后可重新登录以加载新版后台。各桌面的 Portal 和快捷键配置见 [README](https://github.com/Love-in-idleness/PicaLens/tree/v0.1.0#使用)。
