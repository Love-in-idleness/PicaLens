首个 Debian 预览包，适用于 Debian 13（trixie）amd64 的 Plasma Wayland，会使用 Debian 更新后的 KWin `4:6.3.6-1+deb13u1`。应用、桌面启动器和 KWin 后端一起安装。

```sh
sudo apt install ./picalens_0.0.1-1_amd64.deb
```

从应用菜单打开 PicaLens，点击 **Choose Window…**，再点击要放大的窗口。可将 `picalens toggle` 绑定为桌面快捷键，用于开始、取消选窗和停止。

原生 Wayland 与 XWayland 源窗已在嵌套 Plasma 会话中通过点击、滚轮和键盘测试。真实显卡的 DRM/OpenGL 与延迟仍待实机验收。
